# Ironveil Protocol

Ironveil Protocol is a round-based tactical first-person shooter built in three.js for the [make.fun threejs-fps-02 bounty](https://make.fun/c/threejs-fps-02). Learn more at the [bounty page](https://make.fun/bounty/threejs-fps-02).

## How to play

Serve `game/` statically (e.g., using `node serve.ts`) and open it in desktop Chrome.

## How to build the entry

Run `MAKEFUN_OUTPUT_DIR=node main.ts` (or `MAKEFUN_OUTPUT_DIR=out node main.ts`) to copy `game/` and `screenshots/` and generate `dossier.json`.
